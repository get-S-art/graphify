# Awesome Design Reference

Usa DESIGN.md di siti reali come riferimento visivo per build di UI. Invece di descrivere uno stile a parole, cita il sito di riferimento.

## Quando usarla
Quando l'utente dice "fai qualcosa che si sente come [sito]" o quando vuoi un riferimento visivo preciso per un componente.

## Repository sorgente
https://github.com/VoltAgent/awesome-design-md/

## Come procedere
1. Chiedi (o inferisci) quale sito usa come ispirazione visiva
2. Fetcha il DESIGN.md corrispondente da https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/designs/[nome-sito]/DESIGN.md
3. Estrai: palette colori, tipografia, spaziatura, componenti chiave, do's & don'ts
4. Applica quei principi al codice che stai scrivendo
5. Adatta al design system di Artur se il target è un suo progetto (vedi skill `brand-consistency`)

## Siti disponibili (categorie principali)
- AI tools: Vercel, Linear, Notion, Loom
- Developer: GitHub, Stripe, Twilio
- SaaS: Figma, Canva, Miro
- Fintech, E-commerce, Media
- Retro Web: siti anni '90 se hai bisogno di nostalgia

## Nota
I DESIGN.md descrivono principi visivi, non sono CSS da copiare letteralmente. Usali come brief di stile.
